Where every number on this page comes from.

The page holds no solver logic. It runs the command-line solver and shows what it wrote.

The log is the solver's log

Each line is streamed from sankhya solve --option log_level=verbose as it is printed. The iteration table you see is the one the engine writes; the chart is drawn from those same lines.

The answer is checked by something that is not us

tools/verify_solution.py reads the model file with its own MPS parser, recomputes activities, the objective, reduced costs and the dual objective from the solution, and passes or fails each check. It links none of the C++.

The comparison is against the real thing

HiGHS solves the same file through highspy, the same call bench/runners/cross_check_highs.py makes. Where it finishes first, that is shown too. The problem statement asks us to compare, not to win.
